## v3

great! let's digging further
first thing first, here's my answers to your questions:
1. 8 items at max. full circle layout
2. do gesture first. keyboard later.
  - hold to open the menu. release to close
  - the menu open immediately on tap. no need to set a threshold
  - drag pointer to the item, then release to activate the item
3. a time entry is composed by three temporal elements: starttime, endtime, duration
  - the user control allow 3 ways to edit the time value
  - 1. change starttime or endtime; duration update automatically
  - 2. lock starttime; change duration; endtime updated
  - 3. lock endtime; change duration; starttime updated
  - tap starttime/ endtime to lock it; this lock is mutually exclusive
  - starttime/ endtime and duration use two different optimized user control
4. edit via modal

let's fill in more details about predefined task and data import/ export

about toolbar
- include pause in the toolbar
- two buttons: (play '▶' / pause '⏸') | (stop '⏹')

about predefined tasks
- there are two optional field: timesegs, estimation duration
- timesegs is a list of enum to indicate which time segment is available for this task
  - defaults to null; null value means this task is available all-day
- set estimation duration to 50 minutes would replace the elapsed time by a countdown timer when user start the task
  - the timer notify users when count to zero

about timeseg enum
- seg0 => 00:00-06:00 & 22:00-23:59
- seg1 => 06:00-10:00
- seg2 => 10:00-14:00
- seg3 => 14:00-18:00
- seg4 => 18:00-22:00

about data import/ export
- all time entry have an uuid to avoid duplication on importing
