first of all, here's my answers to your questions:
- ring menu: visual feedback while dragging? cancel zone?
  - yes, highlight the current focusing item
  - yes, set the center as the cancel zone
- time control: what widget for editing startTime/endTime? (dial, scroller, etc.)
  - basic validation: startTime must not surpass endTime; endTime must not prior startTime
  - use dial-like user control to update an existing time value
  - user drags the minute hand of a dial on initialized, the time value is set after users release the hand
  - dragging the minute hand over 12 marker clockwisely would set the hour +1
  - dragging the minute hand over 12 marker counter-clockwisely would set the hour -1
  - dragging the minute hand to the center of the dial would cancel the action
  - set the step to 5 minutes, thus, there are totally 12 steps for the dial
- duration control: what widget for editing duration? (stepper, slider, etc.)
  - basic validation: duration must be a positive value
  - use dial-like user control to update an existing duration value
  - single tap to use additive operator, double tap to use assignment operator
  - set the step to 5 minutes, thus, there are totally 12 steps for the dial
  - for single tap mode, the minute hand is initialized at the 12 marker
    - it is possible to drag counter-clockwisely to apply a negative value
  - for double tap mode, the minute hand is initialized at the current duration value
    - it is impossible to drag counter-clockwisely
  - dragging the minute hand to the center of the dial would cancel the action
- pause behavior: does paused time create a gap, or is it stitched together?
  - remove the pause from the design as it would complicate the calculation of time entry duration
- countdown notification: sound, visual flash, or both?
  - use sound and browser notification API
