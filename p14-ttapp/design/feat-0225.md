#### UI

the UI for tabstrip looks like this:
```
[1][2][3]...[+][🗐]
[   desc   ]
- [blank row for insertion]
- [task 1]
- [task 2]
- ...
```
the first row is the tabstrip, number starts from 1 capped at 8
- end of the first row are two buttons, the first one is to add a new blank taskset
- the second button is to duplicate the current taskset to a new tab

the second row is an editable description field (a multi-line text field)
the third row is the `task-list` of the current taskset
- we will made a few more changes to the `task-list` as below
